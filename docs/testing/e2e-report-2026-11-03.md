## Environment limits

- **The screen was locked for the whole run** (`CGSSessionScreenIsLocked = true`). So the display link never ticked (`ticks: 0`), `screencapture -l` failed ("could not create image from window"), and cold start's `first_frame` mark fell back to its 2 s timer. Every capture below is the app's own render (`shot`, or `capture`'s `-app.png`). Those can't see QuickLook views, and WebKit only sometimes draws in a background window.
- **Within the ground rules throughout.** No OS input, no window raised, dev instances only (`e2e-*`, herdr sessions `azj-dev-e2e-*`), no real SSH, no clipboard, keychain or `~/Downloads`, no `herdr update`. Before running `machines.sh` and `mockup.sh`, I confirmed on two throwaway sessions that `herdr --session X` beats an inherited `HERDR_SOCKET_PATH` (this shell runs inside the maintainer's herdr). B15 kills only processes whose *responsible* process is the dev app (`e2e/killrp.py`), never another app's WebKit or QuickLook helpers.
- **Ghostty:** the worktree's empty `vendor/ghostty` was briefly symlinked to the main checkout's built copy, then restored. Not committed.

## Failures

### F1 (B6b): `azj preview open` doesn't work from a terminal tile
**Repro:** in a terminal tile, `azj preview open --path plan.md`.
**Expected:** the PRD's plan-review story; the agent opens its plan beside itself.
**Actual:** `azj: invalid_state: tile_… is a terminal tile, not a preview tile`, exit 1. `--tile` defaults to the caller, a terminal. `azj tile split --right --kind preview --path plan.md` works (relative path resolved correctly) and is what the test used next.
**Evidence:** `.dev/e2e.out/B6-plan/plan/open.out`, `split.out`. Fix either the command (open a preview beside a non-preview caller) or the docs/plan wording.

### F2 (B7b): `azj files open --path <relative>` resolves against azj's folder, not the files tile's root
**Repro:** files tile on `$fx/azulejo`; from any other folder run `azj files open --tile <files> --path README.md --target terminal`.
**Expected:** a terminal in `$fx/azulejo` (`--path` is "Absolute, or relative to the tile's root").
**Actual:** a terminal in the folder azj ran from. The CLI absolutises every `path` param against its own cwd (`core/crates/cli/src/lib.rs`, `absolutise_paths`), before the core can resolve it against the root. With an absolute path it works (PASS in the same run). The same probably hits `files reveal`/`files expand`.
**Evidence:** `.dev/e2e.out/B14-api/files-terminal-file.json` (cwd = worktree root).

### F3 (B4b): the moving tile's header strip vanishes mid-swap
**Repro:** `apps/macos/automation/anim.sh --slow`, step `03-swap`, capture at 450 ms of 1500.
**Expected:** headers and caps move with the tile (D.5).
**Actual:** the focused card moving left has its ring and body but no header strip; the strip's place is window colour. By 900 ms it's back. At normal speed that's a few frames of missing header. Seen in the in-app render only.
**Evidence:** `e2e-v1/b4-swap-mid-header-missing.png` (local capture).

### F4 (D5): reconnect timings regressed
See P1 under Performance.

## Fixes to test scripts (no product code changed)

- `scripts/release/test-dogfood.sh`: `start_installed` slept 0.3 s and hoped the stand-in had set its TERM trap. On a busy machine the first run of a freshly signed bundle can be slower, the TERM landed first and killed the "stuck" stand-in. It now waits for a ready file the stand-in writes after its trap. 5/5 after.
- `apps/macos/automation/machines.sh`: the parked (disabled) machine named herdr session `default`. It never connects, but if a bug made it connect, the stand-in would reach the maintainer's default session. It now names `azj-dev-<name>-parked`.
- `scripts/nfr/lib.sh`: honours `AZJ_DEV_NAME` (default `nfr`) instead of forcing it.

New scripts: `apps/macos/automation/e2e/` (`run-all.sh` runs them in turn): adopt, chords, dyn, animoff, agents, plan, ended, api, git, reload, stab, gallery (`E2E_LIGHT=1` for C5), motion; helpers `lib.sh`, `hd` (herdr on `azj-dev-e2e*` sessions only, never `update`), `killrp.py`.

## Other findings (not visual)

- `find` (⌘F) is bound by default, but it only flashes "Find lands with the terminal tile (1.7)": unimplemented, with a stale message.
- The API silently ignores unknown params: `layout.split` with top-level `kind`/`url` (instead of `content`) makes a terminal and replies OK.
- `layout export` writes `cwd = ".../T//azj-e2e…"` (double slash) for a workspace whose cwd came from `$TMPDIR`.
- "done" can come from `report-agent`: in one B5 run, working → idle on an unfocused tile became `done!`, while attention.azs expects plain idle (and compare-v1 #8 says done can't be simulated). It's either timing-dependent or the doc is out of date.
