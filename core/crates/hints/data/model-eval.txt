# Command evaluation corpus for the on-device model spike (smart select's
# `c` category): the rules (detect::detect) against Apple's on-device model
# (apps/macos/tools/HintsModelBench). Same format as hints-corpus.txt; every
# screen is fictional (example.invalid hosts, documentation IPs, made-up
# names). Categories: agent (commands in an agent's prose), code (code
# blocks), prompt (shells with typed commands), error, status, banner,
# editor (vim, tmux, editor status rows), wrapped (agent hard wraps).
# A command typed over continuation rows is expected on one line, as Copy
# gives it; code in a file open in an editor isn't a command to run.
#
# Scored by `cargo test -p azulejo-hints --test model_eval -- --nocapture`
# (rules) and `just hints-model-bench` (rules and model).
